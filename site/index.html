Behavioral ransomware detection · Windows 10/11

Catch ransomware by what it does, not what it’s called.

A free Windows agent that watches every new process through Sysmon, turns its first 50 actions into 99 behavioral signals in Rust, and scores it on your own CPU, so renamed, repacked and never-seen-before samples are judged by behavior.

Download for Windows Alert-only by default · MIT licensed

92.1% of unseen malicious processes flagged, 2.8% false alarms measured on 294 held-out processes the models never trained on.

How it works

Three steps, all on your machine.

No signatures to update. The models read how a process behaves in its first moments.

01 — See

Sysmon records every process

Process starts, file writes, registry changes, network connections and DNS lookups are captured by Microsoft Sysmon with a minimal, purpose-built config.

02 — Understand

A Rust sensor builds 99 signals

Each process’s first 50 events become a behavioral fingerprint: command-line traits, launch location, parent/child lineage, file and network patterns, timing bursts. It matches the training features exactly.

03 — Decide

Two tiers, fast then careful

A small on-device model settles clear cases immediately. Uncertain ones go to a deeper Tier-2 network. Signed Windows tools that attackers abuse are still watched.

Alert first, kill when you’re ready. Out of the box every threat is logged, never killed. Switch to enforce mode only after you’ve seen how it behaves on your machines.

Private by design. Scoring runs locally. Only uncertain processes are escalated, and only to a Tier-2 service you run yourself.

Know the limits

What it doesn’t do yet.

Not a replacement for Defender

Run it alongside your antivirus. It adds behavioral detection; it doesn’t replace signatures, patching or backups.

Trained on lab data

The models learned from the LMD-2023 lab dataset. Real machines run different software, so tune with alert mode first.

User-mode, not tamper-proof

The agent runs as SYSTEM but has no kernel driver or self-protection. A process with admin rights can stop it.

Judged on first moments

Each process is scored on its first 50 events. Slow or multi-process attacks can stay under that window.
