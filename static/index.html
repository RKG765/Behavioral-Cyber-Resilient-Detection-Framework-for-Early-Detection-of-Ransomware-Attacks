Engineering Challenges & Production Fixes

1. WMI Self-Suspension & OS Deadlocks
Prevented agent self-targeting and Windows BSODs via dynamic SELF_PIDS registration, hardened CRITICAL_OS_SAFELIST, and asynchronous ThreadPoolExecutor(8) decoupling.
2. The Behavioral Observation Paradox
Suspended processes cannot generate Sysmon events. Solved via dual-mode observation: unknown binaries run under sliding-window surveillance (30s window, 2s polling), terminating immediately if score hits ≥0.90.
3. ResNet Small-Batch Tabular Collapse
LayerNorm destroyed tabular feature variance on Seed 2024 (55% collapse). Swapped to BatchNorm1d and pruned PROJ_DIM to 64, permanently stabilizing mean accuracy at 96.35%.
